## Deskripsi
Proyek ini dibuat untuk mempelajari operasi file (File I/O) dan penanganan kesalahan (Error Handling) menggunakan Python.

## Materi yang Dipelajari
1. Membaca file menggunakan mode `r`.
2. Menulis file menggunakan mode `w`.
3. Menambahkan isi file menggunakan mode `a`.
4. Memproses data dari file teks.
5. Menangani kesalahan `FileNotFoundError`.
6. Menangani kesalahan `ValueError`.
7. Membuat rekap nilai dari file teks.

## Struktur Folder
- `data/`: menyimpan file catatan, nilai, dan hasil rekap.
- `latihan/`: menyimpan kode latihan 1 sampai 6.
- `tugas/`: menyimpan program rekap nilai.

## Cara Menjalankan Program
Jalankan perintah berikut melalui terminal VS Code dari folder utama proyek.

```bash
python latihan/01_tulis_file.py
python latihan/02_baca_file.py
python latihan/03_append_file.py
python latihan/04_proses_baris.py
python latihan/05_file_not_found.py
python latihan/06_value_error.py
python tugas/rekap_nilai_file.py
```

## Hasil
Program tugas praktik membaca data nilai, melewati data yang tidak valid, menghitung statistik nilai, dan menyimpan hasil rekap ke `data/hasil_rekap.txt`.
